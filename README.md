POINTS SMP PLUGIN

A plugin designed to for The Points SMP. The plugin allows players to earn points through earning advancements and killing players.
The plugin offers special admin commands that allow admins to remove or add points to players
There is a leaderboard command which players can use it to get the top 10 players who dominate the SMP with the most points

You can also Earn Points by killing the wither, warden and ender dragon
